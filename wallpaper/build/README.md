# 应用图标

`icon.icns` / `icon.iconset/` 是**生成出来的**，不是手画的。要改就改脚本重跑，
别直接修 png —— 否则下次谁重跑一遍你的修改就没了。

```
cd wallpaper/build
python3 _icon-build.py     # → icon-source-1024.png
python3 _icon-pack.py      # → icon.iconset/（十档）+ icon.icns
```

⚠️⚠️ **第二步 0.9.137 之前不存在** —— iconset 和 icns 是当时在终端里临时拼的，
而这份 README 却写着"要改就改脚本重跑"。那句话当时是**假的**：
改了 `_icon-build.py` 之后没有任何东西能把它变成 iconset。
⟹ 判据：**"生成物"要有一条能重跑的路，否则它就是手工产物** ——
而手工产物的问题不是麻烦，是"下一个人不知道怎么复现"。

脚本分工：

| 文件 | 干什么 |
|---|---|
| `_icon-gen.py` | squircle 遮罩（macOS 的圆角是超椭圆 n≈5，不是圆角矩形）、渐变底、四周 8.5% 留白 |
| `_icon-curtain.py` | 极光帷幕渲染 + `bg()` / `stars()` 那些公用件 |
| `_icon-star.py` | **现在用的**：圆角五角星（参数和判据在它的 docstring 里） |
| `_icon-build.py` | 串起来 + 输出 1024 源图 |
| `_icon-pack.py` | 源图 → iconset 十档 + icns（带自校验） |

## ⚠️ 现在的设计：左下角的圆角五角星（0.9.137）

用户 2026-08-02：「画一个五角星，每个角是圆滑的，在左下角，不要完全显示，
遮挡一部分，颜色就还和现在的一样」

四轮反馈定下来的（12 个候选，最后选 k3）。**两个反直觉的点：**

**① "胖乎乎"的主导参数是内外半径比，不是圆角。** 几何标准的五角星是 0.382
（最瘦），0.42 那版用户说"都太瘦了"。定稿 **0.62**。
而圆角（内谷 .50 / 外角 .16）管的是"圆滑",不是"胖"。

**② "大小"和"切多少"是两个自由度**（半径 + 中心位置）。我走错过两次，
都是只推一个参数：
- 只推"胖" ⟹ 胖了但只露出一两个角，认不出是星星
- 只推"大" ⟹ 大了但星星比画布还宽，左边和下边被整条裁成直边，
  看起来像"一块青色的形状"

⟹ 放大之后**必须把中心往右上挪**，切口才只落在左下那个角上。

⚠️ 极光帷幕那版**没删**（`_icon-curtain.py` 里 `curtain()` 还在，星星版也用它的
`bg()`/`stars()`）—— 想换回去改 `_icon-build.py` 一行，历史版本见 git。

## ⚠️ 为什么帷幕不是"一条弯曲的发光带"（0.9.137 之前那版的判据，留档）

做废了三轮才想明白：极光是**帷幕**，上缘锐而亮、往下垂落散开，**上下不对称**。
画成粗细均匀的曲线就变成丝带／DNA 螺旋／均衡器，一眼假。`curtain()` 里
`up=0.020`（上缘溢光很小）对 `height=0.38`（下缘垂落很长）就是这个不对称。

竖向射线（`ray=`）是极光和"发光色带"的另一个区别，而它**只作用在帷幕身体上、
不碰上缘亮芯** —— 否则上缘会被啃出缺口。

## ⚠️ icns 是手写二进制的

生成它的机器（Linux）没有 `iconutil`，所以 `_icon-build.py` 之后是按 icns 容器
格式直接拼字节（magic + 类型码 + PNG 载荷）。结构自校验过（11 档都能解回合法
PNG），**但"Finder / Dock 认不认"在那台机器上验不了**。

⟹ `build-mac.sh` 在真机打包时会用 Apple 的 `iconutil` 从 `icon.iconset/`
**重生成一遍**，得到权威产物。仓库里那个手写的 icns 只是兜底。

## ⚠️ 为什么从三条收到一条（同上，留档）

三条时波形是同一条曲线平移下来的 ⟹ 看着像等高线，规律而无表情。只留一条之后
**左右波峰的高差**才立得起来（左 .42 / 右 .32，y 越小越高）—— 那 0.10 是试出来的：
0.06 看不出，0.14 已经歪。

亮度三个杠杆必须**一起收**（`alpha` / `core_boost` / 外发光 `glow_a`）。只压一个没用：
压 alpha 上缘亮芯照样刺眼，只压亮芯身体反而显得比上缘还亮。
