壁纸层

-

真壁纸层是默认，因为它能覆盖顶部菜单栏那 25px（和 mac 原生壁纸一样）。
而那一层本来收不到鼠标：所以我们抓全局鼠标事件再注入进去， 点击、拖拽、滚轮都能用。
⚠️ 需要辅助功能授权，而开发模式（npm start）拿不到：授权列表里只有 Electron/终端，没有本应用。这一项要打包成 .app 才能用 （npm run dist:mac）。
（我一开始以为监听鼠标不需要授权，实测证伪了：helper 会报"已启动" 然后静默收不到任何事件。）
⚠️⚠️ 那个授权框是 macOS 自己弹的，不是本应用弹的：未授权的进程一调用全局监听，系统就弹。所以没授权的话每次开应用、 装载第一个壁纸时都会弹一次（进程每次都是新的）。
⟹ 这就是默认关的原因：不开这个开关，一个框都不会出现。 要点击特效就开它、授权一次（授权后要重开本应用），从此不再弹。
⚠️ 普通窗口压最底时要关掉转发：那种窗口自己能收鼠标， 再转发一次会变成双份事件（点一下算两下）。

音源


      

        「全系统」音源走 CoreAudio 进程 tap（macOS 14.2+）：不需要屏幕录制权限，菜单栏也不会显示"正在共享屏幕"。
        
⚠️ 而这两种情况会退回 ScreenCaptureKit（那时才要屏幕录制，
        菜单栏会显示"正在共享屏幕"）：
        
　① 「只抓网易云」：tap 抓不了单个 App
        （能做，但要多走三步链，每步都可能静默失败 ⟹ 暂时不做）
        
　② macOS 低于 14.2，或者 tap 起不来（那时上面那行状态会说原因）
        
　⟹ 上面那行状态会写清当前用的是哪条。
        
⚠️ 而这只影响音频：手势走摄像头权限（菜单栏绿点）、
        鼠标转发走辅助功能权限（不亮任何指示）。三条链是分开的。
        
　（我原来在这里写"CoreAudio 进程 tap 同样要屏幕录制权限"，
        那句话是我凭印象说的、没验过：用户反问后写了两个探针去量，
        结论是不需要：tapErr 0 + screenRecordingGranted
        false + 98% 非零采样。⟹ 一句没验的话挡住了一条真出路。）
        
　不想看到它：把音源切成关（或「合成测试音」，那条不碰
        ScreenCaptureKit）：指示会立刻消失，代价是壁纸不跟着音乐动。
        
⚠️ 「只抓网易云」需要 macOS 14.4+；更早的系统会自动退回全系统混音，
        那时候视频和提示音也会让画面跳动：上面那行状态会说清楚当前是哪种。

诊断

    

      

        录一段原始关键点，用来标定阈值。所有测试用的都是合成手，而合成手缺的不是噪声的
        大小而是它的时间相关结构（相邻帧一起漂、丢跟踪后重新检出会跳）：独立噪声会自己平均掉，相关噪声不会，而那个差异决定判定在真手上成不成立。
