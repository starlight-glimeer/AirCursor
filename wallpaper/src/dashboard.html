手势未开启

骨架是独立一层，盖在所有窗口之上、鼠标穿透 —— 所以在任何应用前面都看得到手在哪。录制时会强制显示，不管这个开关。

点击通道：检查中

授权后要完全退出再打开 —— macOS 只在进程启动时读这个授权。

诊断

录一段原始关键点，用来标定阈值。所有测试用的都是合成手，而合成手缺的不是噪声的 大小而是它的时间相关结构（相邻帧一起漂、丢跟踪后重新检出会跳）—— 独立噪声会自己平均掉，相关噪声不会，而那个差异决定判定在真手上成不成立。

骨架几何：等骨架层启动

连续控制（不用录，开了就能用）

可录制的动作

手感调参

用的是 AirCursor 那套滤波器：平滑强度越大越稳越迟钝；快速跟随越大越跟手但越抖；静止死区是手停住的判定门槛。

壁纸与音乐

窗口层级和音乐联动。

壁纸层策略

看不见壁纸就换一个，或按 ⌃⇧L 循环。desktop 是真壁纸层但收不到鼠标；悬浮最上层一定看得见，用来先验渲染效果。

音乐

—

读的是 macOS 的「正在播放」，所以网易云、Apple Music、浏览器都算。需要 brew install media-control；没装就只是不跟随音乐，壁纸照常。

诊断

手骨架的开关在「手势录制」那一栏 —— 它是独立窗口，不属于壁纸。
