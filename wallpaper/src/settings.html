三层图片

图片由你自己准备：背景整张壁纸、主体抠好的人物（透明 PNG）、碎片取自壁纸的一小块（透明 PNG 最好）。

壁纸层策略

看不见壁纸就换一个。desktop 是真壁纸层但收不到鼠标；悬浮最上层一定看得见，用来先验渲染效果。也可以按 ⌃⇧L 直接循环。

景深与排布

手势

双手拇指+食指捏合，两手拉开 = 推进放大，合拢 = 拉远缩小。
单手移动 = 视差跟随，快速横挥 = 主体左右转。

手势未开启

音乐

读的是 macOS 的「正在播放」，所以网易云、Apple Music、浏览器都算。需要 brew install media-control；没装就只是不跟随音乐，壁纸照常。
