# 自带壁纸

放这儿的是**我们自己写的** Web 类型壁纸（不是从工坊下的）。

## 怎么用

把整个目录拷到你的壁纸库，然后在「我的壁纸」里点它：

```
cp -R wallpapers/album-orbit ~/Documents/GestureWall/Wallpapers/
```

⚠️ 目录名随便改，但**里面必须有 `project.json`** —— 那是我们扫描壁纸的判据。

## album-orbit（唱片环绕）

专辑封面排成同心圆环，**鼠标拖拽 360° 转视角**、滚轮拉近拉远、点击暂停旋转。
跟着系统正在播放的音乐动：低频推近处的封面、中频转边缘亮度、高频让粒子闪。

灵感来自 Open Wallpaper Engine 那个"播放音乐时的歌单背景"。

⚠️⚠️ **要拖得动，得在「壁纸与音乐 → 壁纸层」打开「转发鼠标给壁纸」**
（那个开关**不需要任何系统授权** —— 全局监听不算辅助功能，2026-08-02 真机验过）。
没打开的话画面照旧转，只是拖不动，而壁纸左下角会有一行提示。

⚠️ 而它是**先有 0.9.108 那个修复才能用的**：在那之前 `drag` 和 `move` 注入的都是
裸 `mouseMove`（不带按键状态）⟹ 页面 `event.buttons === 0` ⟹ 拖拽判定不成立，
症状是"点得动、拖不动"而且不报错。

### 技术选择

| | 为什么 |
|---|---|
| canvas 2d，不用 WebGL | 一堆正对镜头的 quad 按深度排序，2d 够用。而 WebGL 的失败模式（着色器编译失败/context 丢失）症状都是黑屏，而壁纸层没有 devtools 入口 |
| 40fps 不是 60 | 这个项目为"壁纸吃满 CPU"栽过一轮（`ctx.filter` 每秒 1.3G 像素）。缓慢旋转 40fps 完全够看，省 1/3 功耗 |
| 无外部依赖、无网络请求 | 壁纸跑在 `file://` 下，而用户机器可能没网 |
| 音频取 `max` 不是直接赋值 | 音频回调比渲染帧快，直接赋值会让两帧之间的峰值被抹掉（看起来"不跟音乐"） |
| 粒子位置由 `i` 和时间算 | 用 `Math.random()` 的话粒子每帧跳到别处，看起来是雪花噪点而不是飘浮的尘 |

### 参数（面板上可调）

封面圈数 / 每圈数量 / 自动旋转速度 / 音频推力 / 显示歌曲信息 / 主色。

⚠️ 主色**会被封面的主色覆盖**（宿主给了 `primaryColor` 的话）——
那是"这首歌的壁纸"而不是"一个固定配色的壁纸"。
